# Unfreeze App - Task Templates Reference

## Overview

This document provides a comprehensive reference of all task templates used by the TaskGenerator service. Each template is categorized by interest and task type, providing personalized learning experiences for users.

## Task Types

1. **READ_QUIZ**: Read educational content and answer multiple-choice questions
2. **REFLECTION**: Write thoughtful responses to prompts
3. **BRAINSTORMING**: Generate creative ideas or solutions
4. **ACTION_PLANNING**: Create concrete action steps
5. **LEARNING_SUMMARY**: Summarize key insights

## Interest Categories

The app supports 8 primary interest categories:

1. Business
2. Coding
3. Fitness
4. Finance
5. Books
6. Marketing
7. Personal Growth
8. Career

## Template Usage Guidelines

### How Templates are Selected

1. **Profile Analysis**: User's interests and goals are loaded
2. **Interest Prioritization**: Interests are ranked based on alignment with goals
3. **Type Rotation**: Different task types are rotated for variety
4. **Random Selection**: Within a type, templates are randomly chosen

### Priority Mapping

Goals influence which interests are prioritized:

- **Exam Prep** → Books, Personal Growth
- **Startup Building** → Business, Marketing
- **Career Growth** → Career, Personal Growth
- **Skill Development** → Coding, Career
- **Fitness/Health** → Fitness, Personal Growth

### Difficulty Distribution

- **Easy**: 10 XP, 3-5 minutes, single concept
- **Medium**: 20 XP, 5-8 minutes, multiple concepts or creative thinking
- **Hard**: 35 XP, 8-12 minutes, complex synthesis (future)

### Quality Standards

All templates must:
- Be factually accurate
- Provide value in < 10 minutes
- Be self-contained (no external resources)
- Have clear success criteria
- Align with user's stated interests

## Expanding Templates

### Adding New Templates

To add new templates:

1. Choose an interest category
2. Select a task type
3. Create content that:
   - Teaches a valuable concept
   - Can be completed in 3-10 minutes
   - Relates to the interest category
   - Has clear learning objectives

### Template Structure

**READ_QUIZ**:
```javascript
{
  title: "Clear, engaging title",
  content: "2-3 paragraph educational content",
  questions: [
    {
      text: "Question text",
      options: ["Option A", "Option B", "Option C", "Option D"],
      correctAnswer: index
    }
  ]
}
```

**REFLECTION/BRAINSTORMING/ACTION_PLANNING**:
```javascript
{
  title: "Clear title",
  description: "What the task involves",
  prompt: "Specific instruction for user"
}
```
